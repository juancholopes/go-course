# Go Course

This repository is a small Go (Golang) learning project focused on backend fundamentals and basic language concepts.

## What this course covers

This project includes hands-on examples for:

- Go basics and project structure
- Variables, constants, and basic types
- Functions and return values
- Collections: maps, arrays, and slices
- Pointers and memory references
- Package visibility and exported vs. private identifiers

## Project structure

- `main.go` — entry point that runs the examples
- `collections/` — examples with maps, arrays, and slices
- `functions/` — salary calculation examples
- `pointers/` — pointer usage and mutation examples
- `types/` — types, constants, and simple calculations
- `visibility/` — package scope, private/public functions, and exports

## How to run

From the project root, execute:

```bash
go run .
```

If you want to verify the module and dependencies first, you can run:

```bash
go mod tidy
```

## Learning goal

The goal of this project is to practice Go syntax and core concepts in a simple, progressive way while building confidence with backend development.
